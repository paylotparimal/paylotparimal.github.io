# Parimal Paylot — Personal Portfolio

A responsive portfolio presenting my frontend development work, project experience, technical skills, and professional contact links.

**Website:** https://paylotparimal.github.io/

## Stack

HTML5, CSS3, and vanilla JavaScript. All fonts and the favicon are included locally. No package installation, build step, or backend is required.

## Features

- Responsive desktop and mobile layouts
- Project notes for FuelFlux, SecureTask, and a travel database project
- Interactive FuelFlux booking concept and SecureTask sample checklist
- Internship experience, education, and a focused technical toolkit
- Professional profile links, email contact, and copy-email interaction
- Keyboard-accessible dialogs, mobile navigation, and reduced-motion support

## Run locally

Download or clone the repository and open `index.html` in a modern browser. You can also serve the repository with a local static server.

## Files

| File | Purpose |
| --- | --- |
| `index.html` | Page structure, content, and metadata |
| `styles.css` | Typography, layout, colors, and responsive styles |
| `script.js` | Navigation, dialogs, sample interactions, and email copying |
| `assets/` | Self-hosted fonts, favicon, and font license notice |
| `.nojekyll` | Static GitHub Pages publishing marker |

## Deployment

Hosted with GitHub Pages from the root of the `main` branch. Changes committed to that branch are published after the Pages deployment succeeds.

## Project illustrations

The project previews are interface and schema concepts. The booking and checklist interactions use sample data and do not connect to live booking or task-management services.
